# ChordPlayer

Experimental MIDI tools for learning 7th chord shells.

- `midi.js` — shared MIDI connection state
- `chords.js` — chord interval & shell detection
- `midi-monitor.html` — raw MIDI event log
- `virtual-piano.html` — SVG piano with key highlighting
- `shells.html` — displays held shell chord names
- `shells-quiz.html` — quiz that tests shell recognition

Open any `.html` directly in a browser that supports Web MIDI (Chrome/Edge).
